# NAS 持仓止盈止损服务

服务读取飞书多维表格“持仓共享与止盈止损”的“持仓主表”，每天 `06:00`、`08:00`、`20:00`：

1. 从腾讯证券获取最新快照和前复权日线。
2. 更新最新价、持仓后最高价、ATR14、MA5/13/34/60、前一日最低价、近13日低点。
3. 更新海指导/狼大信号和狼大当前保护线。
4. 用户只填写“证券名称”和“成本价”；系统自动识别代码、市场并更新其余风控字段。
5. 自动计算“我的最终止盈价/止损价”和计划动作；海指导止损线采用可审计的系统补充规则，不冒充其固定原话。
6. 把报告写入统一消息数据库，由现有飞书机器人推送并提供给 AI 历史检索。

核心公式：

- 海指导 ATR 止盈线：`持仓后最高价 - 2 × ATR14`
- 狼大 13 日止损线：`近 13 日低点 × 0.97`
- 狼大日通道线：`记忆点 × 0.97`
- 狼大周通道线：`记忆点 × 0.95`

诊断命令：

```bash
python /app/portfolio_risk.py --self-test
python /app/portfolio_risk.py --dry-run
python /app/portfolio_risk.py --run-now
```

`--run-now` 默认更新表格并只写入历史库，不推送；加 `--notify` 才推送。
